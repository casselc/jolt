The aspect series was replayed once from the historical v0.8.1 base
`9b7683953b444ece2a2e783e8fa46d31177bb476` onto the exact v0.8.3 release.
The replay retained upstream v0.8.3's new `arraybacking` CI gate, retained the
aspect `aspectsmoke` gate, and preserved the existing `errorreport` and
`errorkinds` gates. Project introspection applies source roots without loading
natives or replacements; runtime and build commands additionally install
providers, namespace replacements, and native libraries. The timeout scaling
gate uses one monotonic nanosecond measurement of two consecutive equal-sized
blocks in the stateful timeout heap and keeps the same-shaped explicit
quadratic negative control.

The focused woven/plain differential passes the v0.8.3 unboxed byte-array
representation through two ordered entry-advice consumers. It requires exact
object identity, in-place signed-byte mutation, and
`ArrayIndexOutOfBoundsException` behavior to survive unchanged.

Generated Chez and Gambit seed changes were deliberately omitted during the
replay so that generated output could not hide source-level conflict
resolution. The seeds are regenerated once from the final replayed sources and
recorded as a separate commit in this epoch.
